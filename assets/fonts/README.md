# Bundled fonts

These unmodified variable TrueType fonts come from the official [Google Fonts repository](https://github.com/google/fonts), downloaded on 2026-10-20. Each family's SIL Open Font License is included alongside its font. No font installation or external font service is needed to run Mnema.

| Family | Upstream file |
| --- | --- |
| Inter | [Inter\[opsz,wght\].ttf](https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf) |
| Inter Tight | [InterTight\[wght\].ttf](https://github.com/google/fonts/blob/main/ofl/intertight/InterTight%5Bwght%5D.ttf) |
| DM Sans | [DMSans\[opsz,wght\].ttf](https://github.com/google/fonts/blob/main/ofl/dmsans/DMSans%5Bopsz%2Cwght%5D.ttf) |
| Manrope | [Manrope\[wght\].ttf](https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf) |

Preserve the font files and their licenses when redistributing the project.
